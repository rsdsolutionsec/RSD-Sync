# Pruebas End-to-End (E2E) — RSD Sync

Este directorio alojará las pruebas E2E completas a partir de las Fases 6–9:
- Flujo completo de mensajes entrantes/salientes por WhatsApp Cloud API (con adaptador simulado o entorno sandbox).
- Intervención humana desde el panel administrativo (`apps/admin`) con pausa garantizada de IA.
- Flujos comerciales y académicos completos del primer cliente **SUMAK** sin confirmaciones autónomas de pagos, ventas, inventario ni matrículas.
